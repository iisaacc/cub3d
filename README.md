# 🎮 Cub3D

**Cub3D** is a 3D game project inspired by *Wolfenstein 3D*, developed as part of the **42 curriculum**.  
The goal was to implement a simple 3D rendering engine using **raycasting**, providing an introduction to computer graphics and game development in C.

---

## ✨ Features

- 🕹️ **First-person 3D rendering** using **raycasting**.
- 🎨 Textured walls, floors, and ceilings.
- 🚪 Collision detection and player movement (walk, rotate).
- 🖥️ Built on **MLX** (MiniLibX), a simple graphics library for the X Window System.
- ⚡ Optimized with **low-level memory management** in C.

---

## 🛠️ Tech Stack

- **Language**: C  
- **Graphics Library**: MiniLibX (X-Window API)  
- **Development OS**: Linux / macOS
